# Genomic background effects on *tim01* eclosion timing — Analysis Scripts

Code accompanying the Bachelor's thesis on how genomic background modifies
the eclosion phenotype of the *tim01* (timeless null) mutant in
*Drosophila melanogaster*.

## What changed compared to your original scripts

- **No more hardcoded paths.** Every script now reads/writes through
  `here::here()` (see `scripts/00_setup.R`), so it works on any machine as
  long as you open the project via the `.Rproj` file (or set your working
  directory to this folder) — no more `H:/eclosion_monitor/...` or
  `H:/get_rois_plate/...`.
- **Trimmed to what's actually reported.** Old exploratory branches, dead
  code, duplicate plot versions, and analyses that didn't make it into the
  thesis were removed. Each script's header states exactly which
  Table/Figure number it produces.
- **Individual scripts kept separate**, as you asked — nothing was merged
  into one giant file.
- **New:** `03_F2_new_genotype_comparison.R` now includes the pairwise
  Watson's two-sample tests for the F2_new (rec_083–089) dataset across all
  three genotypes (WT vs. mutant, WT vs. heterozygous, heterozygous vs.
  mutant) — this was the comparison you were still missing.
- **Manual eclosion corrections** (previously typed directly into the
  detection scripts) now live in their own CSVs under
  `data/F2_new/manual_corrections/`, one per recording. This makes the
  detection script itself a reusable template instead of eight near-copies.

## How to run

1. Copy your raw data files into the matching `data/` subfolders above
   (same filenames as your original scripts expected).
2. Open the project in RStudio (create a `.Rproj` in this folder if you
   don't have one yet: File → New Project → Existing Directory).
3. Run scripts in order: `00_setup.R` is sourced automatically at the top
   of every other script, so you can just run `01_`, `02_`, `03_`, `04_` in
   sequence. `detect_eclosion_template.R` is only needed if you're
   reprocessing raw recordings from scratch (change `rec_id` at the top to
   switch recordings).

## Note on `watson.two.test()` p-values

R's `circular::watson.two.test()` doesn't return an exact numeric p-value —
it reports which critical-value band the statistic falls into (e.g.
`0.001 < P < 0.01`). `print()` the test object to see the band and copy it
into your results table by hand, same as you already did for Table 17.
